# 🥔 Lay's Crunch Hub

### A Web-Based E-Commerce Platform for Lay's Products

Lay's Crunch Hub is a web-based e-commerce application designed to provide users with a simple and attractive online shopping experience for Lay's products.

## 🚀 Website Flow

The application follows this user flow:

**Register → Login → Dashboard → Cart → Payment → Logout**

1. **Register** – New users can create an account.
2. **Login** – Registered users can securely log in.
3. **Dashboard** – Users can browse available Lay's products.
4. **Cart** – Users can add products and manage their shopping cart.
5. **Payment** – Users can proceed to the payment interface.
6. **Logout** – Users can safely log out of their account.

## ✨ Features

- 🔐 User Registration
- 🔑 User Login
